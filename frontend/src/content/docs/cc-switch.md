# CC Switch安装指南

CC Switch 是用于管理和切换 Claude Code、Codex、Gemini CLI 等 AI 编程工具配置的桌面应用。

## 下载

请通过官方渠道下载：

- [CC Switch 官方网站](https://ccswitch.io/)
- [GitHub Releases 官方下载页](https://github.com/farion1231/cc-switch/releases)

## 按系统选择安装包

- **Windows**：选择 `.exe` 或 `.msi` 安装包；如果不想安装，可以选择 Portable 便携版。
- **macOS**：根据芯片选择 Apple Silicon（M 系列）或 Intel 版本。
- **Linux**：根据发行版选择 `.AppImage`、`.deb` 或 `.rpm` 文件。

## 完成安装

下载完成后，按照系统提示完成安装并启动 CC Switch。首次使用时，可以在应用中添加或切换对应的 AI 编程工具配置。

请只从官方渠道下载，不要使用要求付费、充值或提供账号密码的非官方安装包。
